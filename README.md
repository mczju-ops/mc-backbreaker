# MC Backbreaker

模仿机械狂欢中的backbreaker

游戏名：史莱姆陷阱

作者：Yikuni

游戏说明：逃离邪恶的史莱姆，利用好友当作挡箭牌，建议人数：3-7人

## 游戏说明

游戏开始时，所有玩家被传送到房间中的指定位置（出生点，可配置）。

玩家之间无法进行pvp，所有玩家获得缓慢效果（可设置），并获得饱和效果。

过一段时间，前面所述的指定位置出现中型史莱姆，这个史莱姆没有AI，无法被攻击。

史莱姆会追踪最近的玩家，并以一定的速度向最近的玩家移动。注意史莱姆不能浮空，不能穿模（需要绕开障碍物）

史莱姆距最近玩家一定距离时（可配置），会停下，并以一个动画向玩家头处飞去，并附在玩家头上，给玩家施加更大的缓慢（可配置）

玩家可用右键将附在头上的史莱姆以一定速度扔出去，但只有史莱姆附身一定时间后才能扔出，扔出后玩家的速度恢复成一开始的缓慢速度。史莱姆落地后，会重新找当前最近的玩家，并持续刚才的步骤，一直追最近的玩家，直到追上

每一轮都有个boss条，用于显示倒计时，倒计时结束时，如果史莱姆已经附在玩家身上，则那个玩家爆炸（仅音效和粒子效果），并死亡，转换成旁观模式。如果没有附在玩家身上，则下次附身到玩家身上，玩家就死。

死一个玩家后，过5s倒计时，史莱姆会重置在出生点，并重新找最近的玩家。

重复若干轮后，直到最后剩余1人，那个人获胜。输出最终存活时间排名，不制作排行榜。

玩家中途退出，则视为死亡，直接进下一轮。

## 其它要求

史莱姆的移动可以设置成移动动画，每一tick计算下一tick移动到哪，中间可以用paper的api进行插值

游戏结束后，所有玩家以玩家的身份，执行lobby {游戏id}以返回大厅

史莱姆需要设置成发光

大部分交互事件都需要设置合适的音效

游戏开始时，在聊天栏输出简短的游戏规则说明

制作时，请用kotlin进行编写，并先将/mnt/d/code/java/projects/mc-dig-wool这个小游戏复制过来作为模板（包括pom等，但别覆盖README），而不是全自己生成代码。

## 插件配置与运行

本项目使用 Kotlin、Paper 26.2 和 MCZJUGameCore 1.0.7。将打包生成的 jar 与 MCZJUGameCore 一起放入服务器 `plugins` 目录，并在 MGC 中为游戏 `mc_backbreaker_slime_trap` 创建房间。房间必须设置 `spawnLocation`，建议将其放在有地面、上方至少两格净空的场地中央；玩家与史莱姆共用此出生点。场地边界需要由地图本身提供。

房间中可调整 `spawnDelaySeconds`（首次出现等待）、`roundSeconds`（每轮爆炸基准时间）、`showExplosionCountdown`（是否显示爆炸倒计时，默认 `true`）、`explosionTimeVarianceSeconds`（爆炸时间随机增减的最大秒数，默认 `0`）、`slimeSpeed`（每 tick 移动格数）、`attachDistance`（附身距离）、`throwDelaySeconds`（可投掷等待）、`throwSpeed`（投掷速度）、`slowAmplifier` 与 `attachedSlowAmplifier`（缓慢效果等级，0 为缓慢 I）。每轮爆炸时间会在基准时间上下限内随机取值，最低为 1 秒。史莱姆会随爆炸临近加快闪烁，并播放音符盒提示音；关闭倒计时文字不会关闭这些预警效果。每局接受 3 至 7 人。

使用 `mvn -DskipTests -Dkotlin.compiler.daemon=false -Dkotlin.compiler.execution.strategy=in-process package` 构建。运行时建议验证：正常附身与投掷、倒计时归零时的两种情况、玩家死亡和中途退出后的 5 秒重置、最后一人结算，以及多房间同时运行。
